Simulation validation
========================

These executed notebooks test analytical graph targets, prescribed-vector
manifolds, sampling sensitivity and replicate inference. They distinguish solver
correctness from biological validation: the simulator does not generate real
splicing counts or validate a fitted RNA-velocity model.
