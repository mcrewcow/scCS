Single-condition analysis
=========================

These tutorials introduce the complete SingleScorer workflow for one
dataset or experimental condition. They cover RNA-velocity preparation,
supervised-furcation definition, DFFP scoring, diagnostics,
visualization, sensitivity analysis, and export.
